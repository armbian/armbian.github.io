## Armbian 26.11.2: stable packages

Armbian 26.11.2 refreshes the CURRENT kernel branch from 6.18.62 to 6.18.63 and EDGE from 7.3.3 to 7.3.4, together covering 28 upstream CVE fixes, while the sunxi and x86 legacy branches move to 6.12.117. On top of the stable release, twelve backported CVE patches were added to the 6.18 branch from armbian/cve, covering issues in netfs, ksmbd, smb client, netfilter, bpf, afs and amdxdna, with one patch (CVE-2026-89788) dropped; the EDGE branch received no new backports this week. On the framework side, the Raspberry Pi bcm2711 edge kernel was bumped to the 7.3 series and the i.MX93 family (including the new Debix Model C) was migrated to 7.3, alongside board additions such as the H96 Max M9 (RK3576) and ArmSoM Sige6, U-Boot updates to v2026.10 for Rock64 and NanoPi R4S, and cryptroot/initramfs fixes for LUKS root setups. Note that qcs6490-edge and qrb2210-edge did not receive the CVE patches because their kernel commit is not at the series base.

**68 kernel packages updated · 2 upstream point releases · 28 upstream CVEs fixed · 12 Armbian CVE patches · 70 framework PRs**
