## Before you start

The device boots Android by default. Set the boot mode in the fastboot menu to start Armbian from the microSD card.

## Installation

1. Insert the microSD card into the device.
2. Hold **Vol -** and power on the device. The fastboot menu opens.
3. Use **Vol -** and **Vol +** to select **Switch boot mode**.
4. Press **Power** to confirm.
5. Press **Power** again to start Armbian.

## Notes

- If the fastboot menu has no **Switch boot mode** option, flash the ROCKNIX ABL first. See the [ROCKNIX wiki](https://rocknix.org/devices/ayn/odin2portal/).
