## Before you start

The boot mode switches select the boot device. Set them to SD boot before you power on the board.

## Installation

- Set the boot mode switches for SD boot:
   - Use switches SW2, SW3 and SW4.
   - Copy the settings from figure "Example Bootmode switch (Full Pincount - SD Card Boot)" in the [TMDS62LEVM user guide](https://www.ti.com/lit/pdf/sprujg8).
