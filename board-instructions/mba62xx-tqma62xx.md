## Before you start

The boot DIP switches select the boot device. Set them to SD card boot before you power on the board.

## Installation

1. Write the image to a microSD card and insert it.
2. Set boot DIP switches S4 to S7 to the **SD-Card** position. Use the table on the [TQ DIP switch page](https://support.tq-group.com/en/arm/tqma62xx/mba62xx/dip_switches).
3. Connect power.
