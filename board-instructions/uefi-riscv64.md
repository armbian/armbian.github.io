## Before you start

This is a generic image for riscv64 computers with UEFI firmware. There is no SD card image.

## Installation

1. Write the image to a USB drive.
2. Insert the USB drive and power on the computer.
3. Open the firmware boot menu. Select the USB drive.
4. GRUB starts Armbian.

## Serial console

- The console is `ttyS0`.
